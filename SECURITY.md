# Security Policy

## Supported Versions

Only version 1 is currently released and supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to whitehat@SAS-Group.org.

We aim to review and respond to reports promptly, and patching is conducted on a monthly or better cadence.
